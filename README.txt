ESDEE LUXURA PORTFOLIO
========================

This is a free, responsive static portfolio website.

FILES
- index.html: complete website
- assets/: portfolio images

HOW TO USE
1. Open index.html to preview the site.
2. To publish for free, upload the folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.
3. Replace the email address in index.html with the brand's real email.
4. Add a WhatsApp button/number and social links when you have them.

The site is mobile-friendly and includes:
- Luxury fashion landing page
- Recent-work gallery
- Category filters
- Click-to-enlarge image viewer
- About section
- Services section
- Contact section
